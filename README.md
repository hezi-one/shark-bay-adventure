# shark-bay-adventure
shark-bay-adventure
﻿鲨鱼湾大冒险 — 本地离线版

如何开始
1. 将 ZIP 压缩包完整解压。
2. 打开 shark-bay-offline 文件夹。
3. 双击 index.html，用 Chrome、Edge、Firefox 或 Safari 打开。
4. 选择开心或快乐，点击“开始冒险”。

本版本全部在本地运行，无需联网、登录、安装依赖或启动服务器。
所有图片、程序和样式均已嵌入 index.html；音效在浏览器中实时生成。
也可以单独复制 index.html 到另一台电脑，直接打开。

操作说明
方向键 ← / → 或 A / D：左右移动
空格、W 或 ↑：跳跃（按住跳得更高）
Shift：按住加速
Q：切换角色
Esc 或 P：暂停 / 继续
右上角扬声器：开关音效
右上角问号：查看操作说明
手机或触屏设备：可使用画面下方的触屏按钮；手机需用能运行本地 HTML 的浏览器打开。

游戏内容
三关：阳光码头、海盗船、彩虹滑道。
从上方踩螃蟹、跳起顶宝箱、收集金币，抵达鲨鱼门。
碰到小旗可设置复活点；掉进水里会失去一颗心。
游戏进度只在当前打开的页面中保留；刷新或关闭页面后会重新开始。

如果双击后显示代码，请右键 index.html → 打开方式 → 选择浏览器。
如果浏览器没有播放声音，先点击“开始冒险”，再确认右上角音效已开启。
